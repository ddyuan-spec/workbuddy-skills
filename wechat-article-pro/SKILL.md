# 微信公众平台文章发布 Skill (专业版 v2.0)

把「写稿 → 排版 → 推送草稿箱」做成一条可复用的流水线。对标文章：《实测WorkBuddy打通公众号！文章自动进草稿箱！》（晓庄）。

## 功能
1. **联网搜索热点** - 获取主题相关热点信息
2. **深度文章** - 撰写 3000-5000 字有深度的文章（默认刘润风格，可切聊天体）
3. **AI 配图封面** - 生成/上传封面
4. **微信兼容排版** - `scripts/wechat_format.py` 一键转成微信编辑器兼容 HTML（table 容器 + 样式白名单 + 字节校验）
5. **自动推送草稿箱** - 对接已连通的公众号后台：`media/upload`（素材）→ `draft/add`（草稿）
6. **发布前 5 步审核门禁 + 反馈回流** - 防 AI 腔、防排版翻车
7. **无话题** - 文章末尾不加任何话题标签

## 一、写作风格
- **默认：刘润公众号风格**（见下方「刘润写作特点」）
- **可选：聊天体**（说人话、有呼吸感）——六法见 `wechat-write` skill：把"我"带进来 / 拒绝爹味 / 适当留白 / 多用短句 / 放弃高级词汇 / 多提问。用户要求"像跟读者聊天"时启用。

### 刘润写作特点
1. 开篇从一个具体商业案例/故事/现象切入
2. 引出一个独特商业观点或洞察
3. 用 2-3 个真实案例论证
4. 适当引用数据和事实
5. 最后给出明确结论与行动建议
6. 语言简洁有力、逻辑层层递进、少用 emoji、段落短、小标题分隔、观点鲜明

### 结构建议
```
# 大标题（核心观点）
## 小标题1：分论点
- 案例/故事 → 分析 → 结论
## 小标题2：分论点
- 案例/故事 → 分析 → 结论
## 总结
- 核心观点回顾 → 行动建议
```

### 禁止事项
- ❌ 末尾禁止任何话题标签（#xxx）
- ❌ 禁止大量 emoji
- ❌ 禁止"欢迎在评论区分享"类话术结尾

## 二、微信兼容排版规范（关键，必过）
微信编辑器兼容性极差，**唯一验证过兼容的结构是 `<table>` 容器**（思路同 HTML 邮件）。直接复制普通 HTML 进去会裂。

**规则**
- 外层骨架：`<table width="100%"><tr><td style="...">`，样式全部打在 `<td>`，内容放 `<p>`
- **允许样式（白名单，仅这些）**：`color / background-color / font-size / font-weight / padding / margin / border / text-align / line-height / font-family / width / max-width / display`
- **禁用（微信不识别，推进去会裂）**：`border-radius / position / linear-gradient / 伪元素 / <section>`
- **克制用框**：AI 排版爱堆背景色块/边框/提示框，一律封顶。取一篇你最满意的已发文章，让排版照它的源码调（金色序号标题、米白导语卡、克制的提示框，一个不多一个不少）

**一键转换**：写好的 Markdown 直接过脚本——
```bash
python scripts/wechat_format.py 文章.md --title "标题" --digest "摘要" --output 文章_微信.html
```
脚本自动：table 容器包裹 + 白名单样式 + 标题/摘要字节校验（见第三节）。

## 三、字节校验（避免 45003/45004 报错）
微信硬限制：**标题 ≤ 64 字节、摘要 ≤ 120 字节**（中文 1 字 = 3 字节）。超长直接报错，推送失败。
- 转换器在生成时自动校验，超长会打 ⚠️ 提示，推送前务必修正。
- 单独校验：`python scripts/wechat_format.py 文章.md --title "..." --digest "..." --check-only`

## 四、自动推送草稿箱 workflow（对接已连通后台）
> 前提：公众号后台已连通（AppID/AppSecret + API IP 白名单已配）。你只需给 AppID/AppSecret，推送由已连通的后台执行；若自建脚本，则把**你的服务器出口 IP** 加进白名单。

**Step A 准备密钥**（2025-12-01 起旧「开发接口管理」路径已失效，改走微信开发者平台）
1. 打开 https://developers.weixin.qq.com/platform/ 扫码登录
2. 「我的业务」→ 选你的「公众号」
3. 「开发密钥」区域：复制 **AppID**；点「启用/重置」拿 **AppSecret**（只显示一次）
4. 「开发密钥」区域把 **API IP 白名单** 加上（WorkBuddy 原生连接填它给的 IP；自建脚本填你服务器 IP）

**Step B 推送两段式 API**
1. `media/upload`（素材上传）：先传封面图拿 `thumb_media_id`
2. `draft/add`（创建草稿）：`articles[0].content` = 第二节转换好的微信兼容 HTML

**参考实现**（自建脚本，需白名单 IP）：`scripts/push_to_draft.py`
```bash
python scripts/push_to_draft.py \
  --appid <APPID> --secret <APPSECRET> \
  --title "标题" --author "作者" --digest "摘要" \
  --content 文章_微信.html --thumb 封面.jpg
```
**安全红线**：AppSecret 只显示一次，勿写进代码库、勿截图发群；IP 白名单是最后防线。

## 五、发布前审核门禁（AI 预检 + 人工判断，必过再推送）

> 原则（呼应「AI 产品经理工作流」三条线之人机切分）：AI 做配角扫重复劳动，人做主角做判断。把能机器化的前置成 **5.0 AI 预检层**，人工只过 **5.1 判断项**，别再从头逐条扫。

### 5.0 AI 预检层（机器先做，省掉人肉重复）
AI 初稿 15 分钟出，先过一遍机器能判的项，列出命中行给人确认：
- **字节校验**：`wechat_format.py --check-only` 自动判标题≤64 / 摘要≤120，超长打 ⚠️（已有）。
- **AI 腔检测**：扫描"首先/其次/总而言之/赋能/一键直达/打造/助力"等套话与四平八稳排比，列出命中行，重点盯开头。
- **截图缺失扫描**：实操教程类逐步检查是否都有真实截图占位；AI 概念图一律标红。
- **钩子命中检查**：标题/摘要是否含「数字冲击+结果承诺 / 痛点 / 反差」之一；对照 `内容资产闭环.md` 第三节钩子命中率表，提示本篇用了哪类钩子、历史真实点开率，辅助选题。
- **结构检查**：是否有"核心观点 → 2-3 分论点(案例→分析→结论) → 总结行动建议"骨架，缺哪块标出。

### 5.1 人工终审判断项（只过这两类，靠人）
1. **内容方向对不对**——主题/结构/关键步骤讲透没？跑题或"浮"的段落拎出来重写（机器给不了判断）。
2. **像不像你 / AI 腔重不重**——通读抓 AI 腔，确认 5.0 列出的命中行已处理；开头尤其盯。

> 原 5 步里的「标题行不行 / 排版对不对 / 截图补没补」已由 5.0 预检覆盖，人工在此只做**确认**而非从头扫。

**反馈回流（接 `内容资产闭环.md`）**：每轮只改一个维度（语气→结构→细节），把"改了啥 / 为什么改"写进 `内容资产闭环.md` 第二节反馈卡；每月一次集中把高频反馈写回本 Skill / `wechat-write`（见该文档第四节），下次不再犯（如"配图只用真实截图，找不到就留占位"）。

## 六、执行流程
0. **选题体检门禁（Line 1）**：动笔前先跑 `选题体检门禁.md`，产出「本篇 AI 边界判定 + 版本策略（1 源 + 变体，不手工维护多份 HTML）+ 钩子预选 3 候选」，确认后再进 1。
1. **搜索热点**：web_fetch / web_search 取主题相关热点
2. **写稿**：按刘润结构（或聊天体）写 3000-5000 字，核心观点贯穿
3. **本地排版**：`wechat_format.py` 转成微信兼容 HTML（自动字节校验）
4. **AI 预检 + 5 步门禁**：先跑 5.0 AI 预检层（字节/AI腔/截图/钩子/结构），再人工过 5.1 判断项；反馈写进 `内容资产闭环.md` 反馈卡
5. **推送草稿箱**：对接已连通后台（给 AppID/AppSecret → 后台推 + 加白名单 IP）；或 `push_to_draft.py` 自建
6. **人工终审**：打开草稿箱核对，确认后发布
7. **发布后闭环（接 `内容资产闭环.md`）**：发布 3-7 天回填反馈卡（打开率/阅读/分享/在看/留言主题/标题 A/B 结果）→ 更新第三节钩子命中率表 → 月末跑第四节风格库迭代，把高频反馈写回本 Skill / `wechat-write`

## 七、注意事项
1. **后台必须已连通**：未配 AppID/AppSecret/IP 白名单，推送会失败
2. **AI 配图要时间**：封面等待 20-60 秒
3. **字数 3000-5000**
4. **禁止话题标签**
5. **安全**：AppSecret 不入库、不截图；白名单是最后防线
6. **依赖**：排版/推送脚本仅用 Python 标准库，无需 pip install
