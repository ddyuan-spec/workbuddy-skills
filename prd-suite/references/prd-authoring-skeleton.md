# PRD 写作骨架（authoring skeleton）

> **用法**：写任何 PRD 前，先按本骨架把「一~九 必含板块」+「§四 每页标准子节」**原样铺好空壳**，再逐格填内容。
> 这样能保证：① 板块只能多不能少；② 每个本期新增/改动页面都按 docx 模板齐备 2.1~2.7 子节；③ 不会漏页、漏图、漏字段来源。
> 填完后跑 `check_prd.py <prd.html> --strict`，缺子节会直接判不通过，就地补齐再定稿。
>
> 复制本骨架到新 PRD 文件，把 `<页面名>` / `<占位>` 替换为真实内容即可。
