# dating-coach 使用指南（用户版）

> 这个 skill 是"综合恋爱教练"：帮你写搭讪/聊天话术、出邀约和约会方案、设计展示面、复盘聊天记录。
> 本文告诉你：**它能干什么、你给它什么、它出回答前必须先问你什么**。

---

## 一、它能帮你做什么

| 能力 | 触发场景 | 例 |
|---|---|---|
| ① 搭讪 / 破冰开场 | 写第一次开口的话 | "帮我在咖啡店搭个讪" |
| ② 聊天回复 | 根据对方消息回话 / 分析 | 粘贴她的消息，说"帮我回这句" |
| ③ 邀约 | 从聊天推进到见面 | "聊得挺好，怎么约她出来" |
| ④ 展示面 | 拍摄清单 / AI 制作图 | "头像照怎么拍""用 AI 做张展示面" |
| ⑤ 约会 SOP | 约会流程脚本 | "第一次约会怎么安排" |
| ⑥ 聊天复盘 | 分析聊天、判断窗口期 | 粘贴记录，"她还有兴趣吗" |

---

## 二、你给我什么，我就能干什么（3 种输入方式）

**方式 1 · 直接描述需求 → 我出方案**
> "帮我写个书店搭讪开场，我想显得稳重一点"

**方式 2 · 只发女方信息 → 我先反问、再作答（你的标准用法）**
- 你**只粘她的消息 / 画像 / 状态**，不用先写自己的情况和目的。我会：
  1. 先速读她的状态表个态（证明我用了你的输入）；
  2. **反问补齐关键缺项**（通常 1–3 个：关系阶段 / 你想让我干嘛 / 你的风格，给选项好答）；
  3. 你补完，我结合知识库给方案。
- 若你连目的都懒得说，我默认按「分析她的态度 + 顺手给句可回的话」处理，但完整可执行方案等你补信息。
> 例：你只发「她：今天好累，加班到现在😩」→ 我回：「她这句是释放疲惫+求关注，窗口偏暖。补 3 个信息我就给话术：1) 你们到哪步了？2) 你想让我帮你回 / 分析 / 邀约？3) 你平时啥风格？」

**方式 3 · 给素材让我沉淀**（课程/文章）→ 提炼进知识库（一般你不用管，已预置）

## 三、出回答前，必须先收集的基础信息（核心协议）

> 规则：信息不够我会问，但**只问 1–2 个最关键的**，不一次轰一堆问题。
> 你也可以直接用第四节的模板一次性填好，我就不用追问了。

### 通用必填（所有场景，缺了没法给准方案）
1. **关系阶段**：陌生人 / 刚加微信 / 聊了一阵 / 暧昧期 / 已约会过
2. **你的风格**：俏皮幽默 / 沉稳真诚 / 随性自然
3. **对方画像 & 当前状态**：大概年龄层、性格（外向接梗 / 内向慢热）、你们现在到哪一步

### 分场景必填清单

| 场景 | 必填信息 | 有了更好（可选） |
|---|---|---|
| ① 开场白 / 搭讪 | 场景（线上App / 线下街头 / 咖啡店书店等）、目标你已知的信息（长相/穿搭/在干嘛）、想传达的人设 | 你当时的状态、之前有无眼神接触 |
| ② 聊天回复 | **对方原话（粘贴）**、上下文（聊了多久/关系阶段）、你的目的（延续话题/调情/邀约铺垫/挽回冷淡） | 你上一句回了什么 |
| ③ 邀约 | 当前聊天热度、之前互动基础、邀约形式（吃饭/活动/散步）、时间窗口 | 她提过感兴趣的某事 |
| ④ 展示面 | 用途（头像/朋友圈/探探等）、想塑造的人设、可拍摄条件 | 现有照片风格、预算 |
| ⑤ 约会 SOP | 约会类型（初次/第N次）、地点&时长、双方熟悉度、你担心的点 | 她偏好（安静/热闹） |
| ⑥ 复盘 | **完整聊天记录（粘贴）**、你的目标、卡点（冷场/被拒/她变冷淡） | 你希望下次达成什么 |

> 标 **粗体** 的是"没有就先问"的硬项；其余能推就推，推不出再问。

## 五、你会拿到什么（输出格式）

- **话术类**（开场/回复/邀约）：1–3 个版本（标俏皮版/稳重版）+ 为什么这么写 + 对方没接住时的退路。
- **分析类**（复盘/兴趣判断）：逐段点评（哪里好/哪里掉分）+ 改写建议 + 下一步话术。
- **方案类**（展示面/约会）：按用途给清单 / 分时段 SOP 表 + 应变预案。
