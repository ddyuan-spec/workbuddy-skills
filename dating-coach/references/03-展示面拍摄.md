# 模块 3 · 展示面拍摄（朋友圈 / 人设 / 外形）

> 来源：Leon《撩妹3.0》视频 2（人设定位）、5（外形建设）、6（朋友圈建设）。
> 核心：展示面不是"装"，是**把真实的你更完整地呈现**——让女生快速了解你的价值，降低线上冷启动成本。

## 3.1 展示面的本质

- 女生对你没反应，往往不是你差，而是**你像一张白纸**——她不了解你，自然没兴趣。
- 现场（搭讪/见面）要靠言语实时输出"你是谁"；**朋友圈/头像/资料是"一次制作、终身存在"的被动展示**，等于不言自明地告诉她你的价值。
- 女生看男人看三样（Leon 原话）：**Looks（外形）· Money（事业/物质）· Status（社会地位）**。展示面要围绕这三样，但不能硬炫。

## 3.2 三大致命错误（必避）

1. **炫富式**：豪车、精致旅游、高档酒店堆满屏 → 有点阅历的人一看就觉得假、low、刻意。
2. **流水账式**：吃饭、逛公园、花草随便拍 → 毫无价值感，像没生活主线。
3. **过度修图/虚假**：和本人差距过大 → 见面即崩，信任归零（见模块4美颜扣分逻辑，同理用于自检）。

> 原则：**不刻意包装，而是更全面完善地展示"你是谁"。**

## 3.3 朋友圈配比与结构

- **内容配比（参考）**：事业 40%（你做什么、有追求）→ 生活 30%（健身/美食/旅行/爱好，体现精致生活）→ 思想 30%（价值观、人生态度，通过文案输出）。
  - 强事业型可 60% 事业 / 10% 生活 / 30% 思想，按自己实际情况调。
- **版面节奏**：每 7 条为一组版面；建议先把 7~21 条"基础版面"建设好再开始高频社交。
- **一张顶三张**：高质量朋友圈应**在一张里融合三元素**。
  - 例（Leon 原案例）：万豪会议室开事业说明会，C位演讲 → ①事业（Leader/老板）②物质（精致食物酒水、西装）③思想（文案讲成立理念、挫折、追求）。一张全包。
- 朋友圈发得好，哪怕搭讪只说"你好，加个微信"也能如虎添翼。

## 3.4 人设包装的 8 个落点

现场聊天和朋友圈都要"披"（包装），让女生明白：**我有选择，你凭什么选我？**

| 落点 | 怎么用（健康版） |
|------|------------------|
| 年龄 | 略成熟感更稳，但别虚报太多，见面即穿帮 |
| 职业 | 突出你负责/有追求，例如"带小团队""自己接项目"，用事实别吹牛 |
| 性格 | 用**故事**承载：上进心=从百名冲到前三；责任心=某次兜底经历 |
| 原生家庭 | 不卖惨、不强调缺爱；传递"被爱、有底气"的感觉 |
| 情感经验 | 不骂前任；"前任都挺好，是我过去不成熟"→侧面证你不错 |
| 社交生活 | 有圈子、有生活，不是孤狼 |
| 痛苦矛盾 | 适度示弱（创业挫折等）增加真实感，但别祥林嫂 |
| 思想/追求 | 文案里露价值观，让同频女生被吸引 |

> 所有"包装"底线：**放大真实优势，不虚构身份**。女生披颜值，你披经历——但别把经历披成假的。

## 3.5 外形建设（线下/头像通用）

- **优先级**：发型 + 上半身 dress nicely > 裤子（简单即可）。
- **低成本可行**：配饰（项链、帽子）就能提调性；基础款衬衫/外套几百块搞定，不必正品。
- **作用**：外形给你正反馈、增强自信，执行时更稳。
- **自检**：不确定自己风格，把照片发朋友圈/发给僚机求反馈，专攻发型与上半身。

## 3.6 拍摄/发圈小抄

- 一图一故事：别只发"我在哪"，发"我在做什么、为什么有意思"。
- 自然光 > 棚拍硬光；生活场景（咖啡馆/球场/书桌）> 摆拍。
- 文案带一点态度/观点，比纯描述更有记忆点。
- 频率稳：别三天打鱼，基础版面建好后保持规律更新。
