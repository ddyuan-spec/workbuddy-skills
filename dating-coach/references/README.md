# dating-coach · references 素材库

本目录存放从**课程视频 + 文章**提炼出的原始/浓缩素材，按模块分文件。
SKILL.md 只放轻量骨架与精华，用到哪篇再用 Read 调阅本目录，避免撑爆上下文。

## 文件命名（与 SKILL.md 模块一一对应）

| 文件 | 模块 | 内容 |
|------|------|------|
| `01-搭讪.md` | 模块1 搭讪开场 | 开场白、破冰、线上/线下钩子 |
| `02-邀约.md` | 模块2 邀约 | 推进节奏、话术、抗拒绝 |
| `03-展示面拍摄.md` | 模块3 展示面拍摄 | 拍照类型/姿势/场景清单、避坑 |
| `04-AI展示面.md` | 模块4 AI展示面制作 | 生成/精修流程、提示词套路、真人感把控 |
| `05-约会SOP.md` | 模块5 约会SOP | 见面→破冰→转场→收尾脚本、地点/话题 |
| `06-复盘.md` | 模块6 聊天记录复盘 | 窗口期判断、兴趣信号、话术修正 |

## 数据怎么进来

素材由用户交给 AI（Buddy）处理，流程：

1. **视频** → 用户给本地路径，AI 用本地 faster-whisper 转写（不上传、隐私稳）→ 文本
2. **文章** → 用户直接贴文本，或给本地文件路径
3. AI 把转写稿/文章**提炼**成各模块对应的 `.md` 文件（保留核心 SOP、话术、避坑，删水词）
4. SKILL.md 各模块"核心方法"从 `待素材填充` 替换为指向本目录的精炼要点

## 提炼标准

- 每篇控制在能讲清方法即可，不堆砌逐字稿
- 保留：可复用的 SOP 步骤、具体话术示例、明确避坑点
- 去掉：寒暄、重复、与主线无关的题外话
- 话术示例标注适用风格（俏皮/稳重）和场景
