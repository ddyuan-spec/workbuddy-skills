# 模块 08 · 多平台引流与复盘（含 Soul 专项）

## 0. 定位：这一块管「入口」，不是管「话术」

聊天只是漏斗后段。开场白发出去没人回，绝大多数情况不是话术问题，而是上游两个环节掉了：

- **展示面不行**（点进你主页的人被劝退）
- **流量质量差 / 内容没做起来**（匹配到的人本来就和你不对频，或根本没曝光）

本模块管「入口」：在哪些平台、发什么内容获得曝光与匹配，怎么用数据复盘定位卡点，以及 **Soul 专项排查 + 爆照评分 + 分层**（原独立模块 08 已并入此处）。与既有模块关系：

- 模块 03 / 04（展示面 / AI 展示面）= 主页吸引力（S）
- 本模块 = 多平台流量来源 + 内容运营 + 跨平台复盘 + Soul 专项（原 08）

> AI 展示面（模块 04）由你另找人跑，本模块不重复，重点放在「不同平台发什么内容」和「复盘」上。

## 1. 流量归因框架（先定位，别乱改）

### 1.1 漏斗七环

```
曝光(推荐流/动态看到你) → 主页点击(点进资料) → 匹配/互关
→ 你发起对话 → 回复(核心痛点) → 加微 → 见面
```

### 1.2 三变量

| 变量 | 含义 | 对应模块 |
|---|---|---|
| **S** 展示面 | 头像 / 相册 / 主页质感 | 03 / 04 |
| **C** 内容 | 你发的动态 / 笔记 / 视频 | 本模块 |
| **O** 开场白 | 你主动发的第一句 | 01 / 06 |

### 1.3 当前症状「开场白没人回」的两种根因

- **A. 匹配到的人本身不对频（流量质量差 / 没曝光）** → 改平台选择 / 内容定向，别改话术
- **B. 点进来的人被主页劝退，或开场白差** → 改 S 或 O

**隔离方法**：A/B 对照实验（见 §4.3）。同一展示面换开场白、同一开场白换展示面，看哪个变量动了回复率。

## 2. 平台矩阵：不同平台发啥

平台分三类：**匹配型**（靠展示面 + 滑动 / 兴趣）、**内容型**（靠笔记 / 视频引流到私域）、**私域型**（靠持续经营）。

> 已定优先跑：**Soul + 小红书 + 抖音 + 积目**（类探探的兴趣匹配型）。探探等纯颜值平台等 AI 展示面（模块 04）回来再重投。

### 2.1 Soul（匹配型 · 已在用，优先续跑）

- **调性**：匿名灵魂匹配、轻社交、年轻人多、容错高
- **发啥（具体清单）**：
  1. **瞬间（图文）**——生活碎片 + 一句话观点 / 反差，留白制造好奇：
     - 「周末自己爬了座野山，下山发现导航把我导进村里了[图]」
     - 「养了三个月的绿植今天突然开花了，它终于认可我这个废物[图]」
     - 「加班到十点，楼下便利店阿姨问我今天怎么这么惨，我竟无法反驳[图]」
  2. **在她瞬间下评论互动（弱连接前置）→ 再私信**：Soul 陌生私信信任度低，正确链路是先在她动态下聊两句，再私信，别冷启动（详见 §5.1.2）。
  3. **语音 / 群聊露观点**：参与兴趣群，自然露观点比私信更高效。
- **展示面重点**：头像 + 瞬间质量（未必露全脸，但要有质感 / 故事感）
- **引流路径**：匹配 → 聊天 → 加微
- **注意**：别硬广、别一上来要微信；先发瞬间再私信，比改话术优先级高

### 2.2 小红书（内容型 · 强引流 ★ 首选）

- **调性**：种草、生活方式、女性用户多、笔记长尾曝光
- **发啥（垂直一个方向，每周 3 篇，别今天穿搭明天炒股）**：
  1. **citywalk / 探店**（男性视角轻松分享，比「教程」有人味）：
     - 标题公式：`[城市] + [具体场景] + [反差/情绪]`
     - 示例：「藏在上海胡同里的咖啡店，老板养了只社恐猫」
     - 封面：原图直出 + 大字标题，别精修到失真（呼应模块 04 避坑）
  2. **穿搭 / 健身 / 户外**：直接复用模块 03 展示面素材，一鱼两吃
  3. **观点 / 情绪**：「男生视角：我们其实也怕被发好人卡」引评论区互动，互动量推流量
- **展示面重点**：封面质感 + 主页统一人设（不是网红脸，是「有意思的普通男生」）
- **引流路径**：笔记涨粉 → 评论区 / 私信 → 微信（**软性**：个人简介 / 评论互动，别在正文留微信号，会被限流）
- **注意**：平台禁导流，靠内容自然吸粉，再用签名 / 评论轻导

### 2.3 抖音（内容型 · 短视频，后置）

- **调性**：短视频、公域算法分发
- **发啥（15–60s）**：
  - 一人食 vlog / 健身打卡 / 旅行碎片 / 反差梗（「表面程序员，周末是攀岩佬」）
  - 示例标题：「花了 20 块做了顿饭，室友说比外卖强」+ 真实出镜
- **展示面重点**：视频里的真实状态（要出镜，所以对展示面/镜头感有要求）
- **引流路径**：主页 / 私信 → 微信
- **注意**：展示面（03 / 04）未达标前性价比低，**先跑小红书**；抖音等出镜素材够了再加

### 2.4 积目（匹配型 · 兴趣社交，类探探但偏兴趣）

- **调性**：年轻人、兴趣标签、潮；比探探更看兴趣契合
- **发啥**：
  1. 兴趣动态（乐队 / 滑板 / 展 / 探店打卡），带地点 / 话题标签
  2. 填满兴趣标签 + 头像风格统一（让系统推同频的人）
- **展示面重点**：兴趣标签 + 头像风格统一
- **引流路径**：匹配 → 破冰 → 加微
- **注意**：内容（动态 / 标签）比纯脸重要一点，是探探的「兴趣升级版」平替

### 2.5 其他平台（按需启用）

- **探探**：纯第一眼，展示面 = 一切；等 AI 展示面（04）回来再重投，现在投是浪费曝光
- **陌陌**：附近 + 直播，同城真实感动态 / 直播间露脸
- **豆瓣**：书影音 + 小组发言 + 广播，文艺慢热，做「有质感」人设背书
- **微信**：附近的人 + 朋友圈持续输出（复用模块 03 配比：事业 40% / 生活 30% / 思想 30%），匹配后点进来看朋友圈会被持续种草

## 3. 内容生产原则（对齐铁律）

- **真实 > 完美**：美颜适度（呼应 §5 美颜 -2 分），不 P 到失真、不与本人差距大
- **价值 / 热爱 > 炫耀**：展示生活方式与热爱，不装富、不炫车表
- **留白 > 全露**：制造好奇，让人想点主页 / 私信，别一帖把底交代完
- **一致性**：跨平台人设统一（昵称 / 头像调性 / 内容方向），别 Soul 文艺男、抖音搞笑男
- **不伪装身份、不批量养鱼**（对齐铁律 5 / 7）

## 4. 复盘体系

### 4.1 指标定义与基准（先用自己数据建基线，别套绝对值）

| 环节 | 指标 | 记录方式 | 参考健康值（示例，需自建） |
|---|---|---|---|
| 曝光 | 动态阅读 / 主页访问 | 平台后台 | 内容型看阅读量趋势 |
| 主页点击 | 点进资料率 | 匹配数 ÷ 曝光 | — |
| 匹配 | 匹配 / 互关数 | 每日计数 | — |
| 发起 | 你主动开聊数 | 每日计数 | — |
| **回复** | **回你的人数 ÷ 开聊数** | **每日计数** | **核心痛点，优先拉** |
| 加微 | 加到微信数 ÷ 回复数 | 每日计数 | — |
| 邀约 | 邀约成功数 ÷ 加微数 | 周计 | — |
| 见面 | 实际见面数 | 周 / 月计 | — |

> 不同平台量级差异大（抖音曝光万级、Soul 百级），**不要横向比绝对值**，比「自己的环比变化」和「同平台 A/B」。

### 4.2 归因决策树

```
回复率低
├─ 匹配质量差？（§5 分层：匹配到的人本身冷淡/错配）
│   └─ 是 → 改平台选择 / 内容定向，不是改话术
├─ 主页点击率低？（点进来的人少）
│   └─ 是 → 内容 / 头像没钩子，强化 C 与首图
└─ 点进来但没回？
    ├─ 同一展示面换开场白 → 回复率变 → 问题在 O（模块01/06）
    └─ 同一开场白换展示面 → 回复率变 → 问题在 S（模块03/04）
```

### 4.3 复盘节奏与 A/B 实验

- **每日（极简）**：发出数 / 回复数 / 匹配数，备忘录随手记
- **每周**：平台对比 + 本周 A/B 结论（同一展示面换开场白 / 同一开场白换展示面 / 同平台换内容方向）
- **每月**：人设迭代，砍掉无效平台、加投有效平台

### 4.4 健康度护栏（对齐铁律）

- 不伪装身份（头像 / 职业 / 生活真实）
- 不批量养鱼、真诚单一
- 尊重对方停意（冷淡 / 拒绝 / 已读不回超次数 → 体面收手）
- 不诱导金钱（铁律 7）
- 平台合规：导流软性，别触平台规则被封号（封号 = 流量归零）

## 5. Soul 专项：流量排查 + 爆照评分 + 分层（原模块 08）

> 来源：用户实战复盘 + 本课程技法库。评分只是**战术筛选工具**，不是对人价值的判定；所有互动以「尊重意愿 + 女性同等付出」为底线（铁律 5 / 7）。

### 5.1 回复率低排查三部曲

先定位"低"到底卡在哪。三块逐一查，别一上来怪平台或怪话术——多数情况是叠加的。

#### 5.1.1 平台（Soul）流量质量排查

Soul 是**匿名 + 兴趣匹配**产品，机制决定了它和探探 / 微信有本质差异：

| 维度 | Soul 特征（排查假设，需你实测验证） | 对回复率的影响 |
|------|------|------|
| 匹配逻辑 | 灵魂匹配（性格测试）、瞬间、语音匹配、群聊，弱颜值 | 纯私信冷开场天然低回复（同类 App 普遍 5%–15%） |
| 用户结构 | 偏年轻（18–28）、一二线居多；「瞬间」+ 礼物体系吸引部分以礼物为目的的用户 | 你感觉"全是捞女 / 低分女"可能是**匹配池 + 资料权重**把你推给了特定人群 |
| 内容流量 | 「瞬间」发布频率 / 互动量直接影响曝光权重 | 不发瞬间、只私信 = 系统判定低活跃，推来的也是低质匹配 |
| 变现生态 | 有礼物、"聊币"类机制，存在职业号 / 机器人 | 部分"女生"可能是运营号，回复率再高也无意义 |

**排查动作（实测 3–5 天记录）**：
- 你每天发几条「瞬间」？互动量多少？→ 不发瞬间就先补这块，比改话术优先级高。
- 你主动私信的对象里，资料完整度、动态更新频率如何？→ 筛掉 0 动态 / 当天注册 / 头像为系统默认的目标。
- 你匹配的「灵魂匹配」标签是否过于小众 / 躺平向？→ 标签影响推送人群。

#### 5.1.2 开场白排查（话术本身）

**Soul 链路铁律**：陌生私信信任度低，正确做法是 **先在她「瞬间」下评论互动（弱连接）→ 再私信**，而不是冷启动。

**开场白自检清单（逐条核对）**：
- [ ] 有没有她的专属细节（她的瞬间 / 头像 / 签名）？没有 = 群发感，必改。
- [ ] 是不是"能回哈哈 / 嗯"的死问题？是 = 死。
- [ ] 有没有先在她动态下互动再私信？没有 = 信任前置缺失。
- [ ] 长度是否 ≤ 3 行？过长 = 压迫 / 像推销。
- [ ] 有没有查户口（哪人 / 多大 / 做啥）？有 = 自杀。

#### 5.1.3 软件 / 账号机制排查

| 排查项 | 说明 | 排查方式 |
|------|------|------|
| 新号 / 未认证限流 | 新注册或未做实名 / 人脸，曝光和匹配质量偏低 | 看「灵魂匹配」每日推荐量是否异常少 |
| 频繁私信被限流 | 短时间大量私信触发风控，后续消息进"可能认识"而非主信箱 | 观察发出去后对方是否"已读"都不到 |
| 资料完整度权重 | 头像 / 签名 / 瞬间 / 标签不全 → 降权，推来的也是低质 | 把资料填满再观察 3 天 |
| 时段 | 凌晨 / 工作日上午匹配质量远低于晚 8–11 点 | 固定在高活跃时段操作 |

> **结论框架**：如果 5.1.3 账号健康 + 5.1.1 你在持续发高质量瞬间，但回复率仍低 → 问题在 5.1.2 话术；如果 5.1.1 匹配池本身低质（全是 0 动态 / 当天号）→ 先换匹配策略（多玩群聊 / 语音匹配 / 瞬间互动）再谈话术。

### 5.2 流程优化：爆照引导 → 评分 → 美颜扣分

目标：**用最低成本先看清对方，再决定投入**。不要在没见照片前投入任何情绪 / 金钱。

#### 5.2.1 爆照引导话术（自然不压迫）

核心原则：用「视觉话题 + 好奇 / 小赌注」让她**自发**晒，比"发张照片看看"自然十倍。

- **绿植 / 宠物 / 桌面钩子**：「刚抢救一盆快枯死的绿植，它一副'这人不行'的表情。你桌上都摆点啥？我赌你比我这堆乱七八糟的强。」→ 引出她晒桌面 / 宠物。
- **场景共鸣钩子**：「这家咖啡店灯光绝了，随手一拍都像电影。你平时拍照什么风格？」→ 她大概率回自己的图。
- **轻赌注钩子**：「我猜你手机相册里 80% 是自拍，敢不敢发张最近拍的（不是自拍那种）让我开开眼😂」→ 用挑衅式好奇逼出生活照。
- **退路**：她只回"哈哈"不晒 → 不追，转轻松话题或自然收尾；她回"关你啥事"类 → 立刻退「惯例好奇，没别的意思」，回安全距离。

#### 5.2.2 评分维度与标准（综合 1–10）

拿到照片后，按 6 个维度各打 0–2 分，合计即原始分：

| 维度 | 2 分 | 1 分 | 0 分 |
|------|------|------|------|
| 五官 | 比例协调、有记忆点 | 普通耐看 | 明显硬伤 |
| 身材 / 体态 | 匀称有线条感 | 普通 | 明显不达标 |
| 肤质 | 真实好皮肤 | 靠妆 / 滤镜撑 | 精修痕迹重 |
| 氛围 / 气质 | 有感染力、干净 | 一般 | 无 |
| 穿搭 | 有品味会搭配 | 随意 | 邋遢 / 廉价感 |
| 妆容 / 造型 | 加分且自然 | 普通 | 翻车 / 过度 |

> 合计 10–12 视为 8+，7–9 视为 6–7，≤6 视为 1–5（原始分，未扣美颜）。

#### 5.2.3 美颜 / 精修识别与扣分规则

**自动 -2 分并标注「疑似精修 / 美颜过重，实际可能低 2 分」**，出现以下任一即触发：

- **皮肤零毛孔 + 塑料光泽**：苹果肌 / 额头高光异常均匀，像瓷娃娃。
- **背景虚化异常**：人物边缘与背景融合生硬、有描边感或"抠图感"。
- **光影不自然**：脸和身的受光方向矛盾，或同一张脸明暗断层。
- **同一滤镜模板**：磨皮 + 冷调 + 暗角，和朋友圈"网红同款"高度一致。
- **五官变形**：下巴过尖、眼睛过大、鼻梁不自然笔直（典型瘦脸 / 大眼算法）。
- **水印 / 拼图**：带美图 / 轻颜 / 醒图等 App 水印，或九宫格精修拼图。

> 标注格式示例：「原始 9 分 → 美颜扣 2 → **实评 7 分**（疑似精修，建议以视频通话 / 线下见面最终确认）」。
> 任何评分都应以**见面或视频**为准终校验，照片分只是初筛。

### 5.3 按分数分层处理策略（含合规边界）

> ⚠️ **成本对等原则（必须守住）**：男生投入了真实成本（算力 / 时间 / 约会开销），女方应**对等支付 / 补偿**这部分成本，男生不被单方面 drained（不爆金币）。可合理引导女方付出金钱（回请、分摊、就实际开销补偿），但须透明、对等、以成本补偿为限、不以获利为目的。无真实 mutual interest 的低分对象 → 不追、不单方面讨好、也不单方面索取。

#### 5.3.1 8+ 高分女：精心准备，争取大结果

- **定位**：高价值邀约对象，值得高投入。
- **流程**：见面地点选有调性、不易踩雷的（精品咖啡 / 小酒馆 / 展览），提前规划动线（见面→破冰→转场→收尾）与备选方案。
- **技法**：全程用技法库（推拉 / 合理推诿）保持张力，不跪舔、不秒回。
- **目标**：关系实质推进（以双方自愿为前提）。

#### 5.3.2 6–7 中分女：邀约对象，促进女方投入

- **定位**：正常邀约对象，走平等约会。
- **流程**：用 `references/02-邀约.md` + 技法库，重点用**合理推诿**让邀约发起权 / 付出归她（"是你先开的口啊""你定时间地点我赴约"）。
- **核心**：促进女方投入（时间 / 情绪 / 小额请客），维持关系天平平衡，不单方面爆金币。

#### 5.3.3 1–5 低分女：低成本、引导对等付出（不爆金币版）

坚持「成本对等」：男生投入了真实成本（算力 / 时间 / 约会开销），不被单方面 drained。

- **无真实 mutual interest → 不投入**：不花时间、不花金钱、不单方面讨好，友好收尾或自然冷却。
- **若继续接触 → 合理引导对等金钱补偿**：你出的算力 / 时间 / 开销，可合理引导她对等支付（回请、分摊、就实际开销补偿），但须透明、对等、以成本补偿为限、不以获利为目的；不欺骗、不超额压榨。
- **原则**：女生要对等支付我们出的成本；男生不爆金币，关系天平才平衡。
