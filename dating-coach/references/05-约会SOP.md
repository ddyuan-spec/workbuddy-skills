# 模块 5 · 约会 SOP（基本流程与执行模板）

> 来源：Leon《撩妹3.0》视频 17（约会基本流程）、15（前提/约会禁忌）、13（收尾/升级）、16（如何让女生倒追你）。
> 核心：约会不是"把人约出来就行"，而是**评估 + 蓄势 + 适度升级 + 转场私密空间**的整体工程。所有肢体/关系升级须以**对方自愿**为前提。

## 5.1 约会的定位

- 搭讪 → 微信聊天 → 约会 是一整体，不分割。
- 女生愿出来，是因为**好奇 + 对你不错**，不是已经确定关系。别刚见面就冲结果。
- 约会的**核心环节是"评估"**：你们互相在试探价值、框架、合不合适。

## 5.2 价值感拉升（40 → 60 分）的三件事

1. **评估（你主导提问）**：提前准备 5~10 个能**挑战她信念**的问题。当她开始自我解释、寻求你认同时，目的达成。
2. **处理她的废测（她反挑战你）**：用四招——**忽视 / 反抛问题 / 重新定义 / 夸张化**。新手多是被测方，能把废测接住不慌，价值感就稳了。
3. **人设植入（一来一往中暴露）**：年龄、职业、成就、性格思想、人生追求、价值观——自然带出，让她看到你的整体轮廓。

> 价值感拉到"她有好感、喜欢"后，才进入蓄势/升级。

## 5.3 升级与"进挪"分级（须自愿）

- **目标**：带她去**私密空间**（车/公园僻静处/你家/酒店），私密空间里道德感下降、距离近，自然升温。
- **肢体测试分级**：
  - C级（基础）：碰肩、碰胳膊。
  - B级：帮她拿头发上的东西、捏脸"你好肥啊"——这两个指标过了，代表可带去私密空间。
- **言语升级**：聊得差不多时问"你觉得我印象几分？有60吗？"→ 正面回应即可挑明升级。
- **升级后必"推"**：牵手/亲近后一定要**退一步、拉开**，维持张力。一直黏着 → 张力消失 → 像在索取 → 价值感掉。
  - 例："手伸出来"（她会伸）→ 握住"还行，不过差点意思，不够骚"→ 再轻推。推拉循环。

## 5.4 转场导向私密空间（执行模板）

1. 确认她**接下来没别的安排**（前提）。
2. 自然提议："我们去看个电影/去公园走走"，**你定，不让她选**（降低决策负担与抵抗）。
3. 进私密空间会有小抵抗 → 化解："你觉得我会对你做什么？没有，只是想跟你待着放松，想去私密点的地方。"
4. 进去后不一定要推到底，但**待过那个空间**本身就是升温场所，出来张力更大。

## 5.5 单次约会结果预期（管理心态）

- 第一次约会有结果 ≈ 30%；更多在**第二次（40~50%）/第三次**。
- 第一次若判断拿不到结果 → **只做简单升温、不推底**，保护张力，留第二次。
- 第二次有了"性能感"，私密空间更好带。

## 5.6 前提意识（贯穿全程，防"朋友区"）

- **男对女前提尽早植入**：聊一两分钟突然"我叫XX，你呢"、问"你喜欢咖啡还是酒"——都在传递"我想认识你/想约你"。
- **跑偏就拉回**：聊职业/年龄/家乡跑远了，用关联法拉回男对女："我后悔跟你聊工作了，我更想以男人和女人的方式聊。"
- **进退都行，往往退更有力**：女生明显推你/挑战你时，用"施格前提"小挑战拉开张力（"你平常都这么跟人聊？太正式了"），她反而想靠近。
- **约会禁忌**：**不要太快牵手/接吻**——距离越远越有感觉，太快亲密动作毁坏张力。

## 5.7 标准 SOP 清单（照着用）

```
[邀约]   抛出低压力邀约 → 她接住（好奇窗口）
[见面]   外形到位 + 早植入男对女前提
[评估]   5~10 个挑战性问题 + 接住她的废测（忽视/反抛/重定义/夸张）
[植入]   聊天中自然暴露职业/性格/追求/价值观
[试探]   肢体C级→B级；言语"我几分？"正面则升级
[转场]   确认她空闲 → 你定私密空间 → 化解小抵抗
[升温]   空间内自然肢体升温，不强行推底
[收尾]   留张力（退一步），保护第二次窗口
[二次]   第一次没结果只升温；第二次冲结果
```

> ⚠️ **底线重申**：所有升级、肢体接触、转场，必须以对方**明确自愿**为唯一前提。任何一步她犹豫/拒绝，立即退回安全距离，不施压。
