# 元素识别与锚点规则

batch-annotate 靠「识别元素 → 分类 → 落锚点」三步走。本文件给判定法与锚点选择。

## 一、按钮类识别（点击产生动作的元素）
- 显式：`<button>`、`<input type=submit|button>`、`role="button"`。
- 类驱动：`<a class*="btn">`、`<div class*="btn">` 等带点击意图的按钮样式元素。
- 行内操作链接：列表里的「编辑 / 删除 / 查看」等文字链接（有功能语义，算按钮）。
- 图标按钮：`<svg>/<i>` 内、带点击意图的图标（如删除垃圾桶图标）。
- **不含**纯导航跳转（除非跳转本身带功能语义，如「去支付」）。

## 二、字段类识别（有数据 / 展示语义的非按钮元素）
- 表单控件：`<input>`（任意 type）、`<select>`、`<textarea>`、富文本、上传控件、开关、单选组、多选组。
- 筛选条件：搜索框、筛选下拉、日期范围等输入区。
- 列表 / 表格：展示列、表格行、行内状态文本块。
- 展示型文本块：只读信息区、汇总数字等。
- 注意：用户明确点名「列表的展示行」也算字段类，不在按钮范畴。

## 三、锚点（data-anno）落点选择
引擎 `anchorOf` 优先级：① `[data-anno]` 显式锚点 > ② 小元素挂自身 > ③ 最近小容器。batch-annotate **统一用 ①**，避免 cssPath 漂移。

| 元素类型 | data-anno 加在 |
|---|---|
| 按钮 | 触发元素自身（`<button>`/`<a>`/图标容器） |
| 字段（有容器） | 字段容器 `.field/.form-item/.row/.item/.col/.cell`（高度 ≤220px 优先） |
| 字段（纯 input 无容器） | input 自身 |
| 列表行 / 展示行 | `<tr>` / `<li>` / 行容器 |
| 弹窗内字段 | 字段自身；弹窗容器加 `data-open="openXxx()"` 钩子，定位自动开弹窗 |

- 序号 `k1, k2, ...` 全局唯一、连续。
- 同元素已有 `data-anno` → 复用，不新建 key。
- 同元素多条批注 → 共用一个 key，seed 里写多条（引擎合并为橙色计数角标）。

## 四、视图（view）判定
- `view` = 元素最近 `.view.active / .page.active` 的 id，或带 `data-view` 的祖先 id。
- 无视图切换的原型 → 写 `"global"`。
- 多视图原型务必填对 view，否则角标在该视图下不显示、跨视图串号。

## 五、截图辅助识别
- 截图仅用于「看清元素长什么样 / 在哪」，**落锚点与写 seed 必须基于 HTML 文件**（需改 DOM + 写脚本）。
- 若只给截图没给 HTML：先向用户要 HTML；或先产出批注清单（annos.json 不含 key，仅 view+text）让其自行应用，再走 ④⑤。
