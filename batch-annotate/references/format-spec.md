# 批注书写标准（权威模板）

本文件是 batch-annotate 的内容标准。**两条总纲**：① 不适用整条省略；② 不冗余、不加标签前缀解释。

---

## 一、按钮类

格式：**「标签 + 冒号 + 内容」**，每条独立一行。只写适用项。

```
功能说明：<描述功能交互>
权限：<描述此按钮操作的权限>            （无特别权限要求 → 整条省略）
前置条件：<使用时前置的条件>            （无前置条件 → 整条省略）
功能实现：<实现逻辑、关联字段、影响的数据、需告知技术处理的部分>   （必填）
文件上传类：<打开上传文件数量、类型等>   （仅文件上传按钮填写）
```

- **功能说明**：用户点这个按钮发生什么（交互层面）。
- **功能实现**：给技术的实现口径——调哪个接口、读写哪些字段/表、联动什么、校验什么。**必填**，缺则反问。
- **权限 / 前置条件**：没有就整条删，不要写「无权限」「无前置」。
- **文件上传类**：仅当按钮触发文件选择时写，注明数量上限、格式（如「单张，jpg/png，≤2MB」）。

### 按钮示例
```
功能说明：点击后将收货表单提交
功能实现：调用 POST /api/order/save；关联字段 收货人/手机号/收货地址；新增 order 表一行；提交前校验手机号 11 位
```
（无权限/前置/上传 → 这三条整条省略）

```
功能说明：点击上传商品主图
功能实现：调用文件上传接口，返回 URL 写入 goods.img；仅允许图片类型
文件上传类：单张，jpg/png，≤2MB
```

## 二、字段类

格式：**只写内容、不写标签**，每条独立一行。所有「【】前的说明文案」都不出现在批注里，只写【】内的准确字段说明。**只写适用项**。

```
<默认数据：如「默认为空」「输入提示：请输入收货人姓名」>      （需编辑填写的数据才写）
<显示：如「默认展示」「不展示，xxx 条件下展示」>              （默认展示则省略；为「否」才写条件）
<是否支持编辑：如「可编辑」「不可编辑」>                     （建议每条写明；整页一致且显然时可整体省略）
<输入限制：如「最多 20 字」「小数点后 2 位」「手机号 11 位」> （仅可编辑 + 自由输入字段）
<选择项：如「固定选项：男/女」「引用：水卡模板（用户新增的水卡模板信息）」> （仅选择字段）
<选中后展示：如「选项名称」>                                  （仅选择字段）
<引用后自动带出信息：如「由『商品ID』带出，展示 goods 表.商品名称」> （仅关联其他字段自动带出）
<计算公式：如「运费 = 重量(kg) × 单价(元/kg)」>               （仅由其他字段计算）
```

- **默认数据**：有默认值的写值（「默认为空」「默认今天」）；有输入提示的写提示文案。
- **显示**：默认展示→省略；为「否」→写「不展示，<条件>展示」。
- **是否支持编辑**：可编辑写「可编辑」，不可编辑写「不可编辑」；受控/条件可编辑必须写明条件。
- **输入限制**：**不可编辑字段不写**；可编辑且支持自由输入才写（格式 / 字数 / 精度）。
- **选择项**：只有选择类字段写。固定选项列出**全部**固定项；引用系统字段写「引用：<系统内对应字段中文名>」——如为「水卡模板」直接写「用户新增的水卡模板信息」。
- **选中后展示**：选择字段才写，描述返回展示的样式（一般=选项名称）。若引用选项含多个字段、不确定展示哪个→反问。
- **引用后自动带出信息**：仅关联其他字段自动带出时写，说明「由哪个字段带出 + 展示哪张表哪个数据」；不确定→反问。
- **计算公式**：仅由其他字段计算时写，说明字段与公式；不确定→反问。

> 字段类不只含输入框，还包括：**筛选条件输入、列表展示列、表格行、开关/单选/多选组、展示型文本块**等一切有数据/展示语义的非按钮元素。

### 字段示例 A（普通可编辑输入）
```
可编辑
默认数据：输入提示「请输入收货人姓名」
输入限制：最多 20 字
```

### 字段示例 B（选择 + 带出）
```
选择项：固定选项：自提/快递
选中后展示：选项名称
引用后自动带出信息：选「快递」后由「收货地址ID」带出，展示 address 表.详细地址
```

### 字段示例 C（计算字段）
```
不可编辑
计算公式：运费 = 重量(kg) × 单价(元/kg)
```

### 字段示例 D（展示行 / 列表列）
```
不可编辑
显示：订单列表每行展示
```

## 三、反问触发清单（拿不准就问，不臆造）
- 按钮「功能实现」不明：不知调哪个接口 / 影响什么数据 / 关联哪些字段。
- 字段「选择项」来源不确定：系统字段中文名、引用哪张表。
- 「选中后展示」涉及多字段，不确定展示哪个。
- 「引用后自动带出信息 / 计算公式」的字段名或表名不确定。
- 权限 / 前置条件描述不清。
- 按钮 vs 字段归类模糊（如文字链接型操作）。
- 多视图原型里某元素归属哪个 view 不确定。

反问时**一次性**抛出编号清单，拿到答案再写回。
